From scattered updates to a clear timeline.

Project context is easy to lose across separate notes and updates. TimeLog gives each project its own timeline, bringing written entries, progress and important dates into a single workspace.

The working product.

  • Create an account and manage independent projects and timelines.
  • Write and edit Markdown entries, with creation, edit and optional event timestamps shown separately.
  • Find entries through text, type and date filters, with chronological sorting and pagination.
  • Track manual or numerical goals, review recent activity and export data as JSON.
  • Use the responsive workspace on desktop or mobile, with timestamps displayed in your account timezone.

Behind the interface.

The frontend uses React and TypeScript. A Hono API runs in Cloudflare Pages Functions, with project and entry data stored in D1. Server-side ownership checks keep each account’s records separate, and session cookies support authenticated access.

Entry creation timestamps stay unchanged when an entry is edited. Distinguishing creation, edit and event times helps preserve the sequence of a project without hiding later changes.

What is live, and what comes next.

The core account, project, timeline and export workflows are deployed. File attachments and transactional email are implemented in the code but are not enabled in production yet. The live product does not currently offer attachment uploads or email-based password recovery.

The next integration work is to connect private attachment storage and an email sender, then verify those flows in production.
